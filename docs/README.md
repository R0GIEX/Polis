# Polis / Ancient City — Asset Pack

Визуальный набор для концепта интерфейса античного города. Стиль: акварель и тонкая тушь, состаренный пергамент, мрамор, бронза, терракота, оливковые и тёмно-бирюзовые акценты.

## Важно
Элементы вырезаны из иллюстрационных листов, поэтому некоторые PNG сохраняют пергаментный фон и могут включать небольшой запас вокруг объекта. Это не прозрачные спрайты. Для использования поверх другого фона потребуется дополнительное удаление фона/маскирование.
Размеры соответствуют доступному разрешению сгенерированных исходных листов; изображения не были искусственно увеличены.
